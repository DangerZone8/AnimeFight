# AnimeFight

A browser-based 2D anime crossover fighting game. Built with vanilla JavaScript and the Canvas 2D API so it runs as a static site and deploys cleanly to Vercel.

## Development

- `npm test` — run the AI and game-logic tests
- `npm run build` — validate the static production files
- `npm run dev` — start a local static development server

## Current scope

The current playable milestone includes a character roster, local player-versus-CPU matches, round timer, health and energy meters, keyboard and touch controls, directional hit checks, four-step combo scaling, animated procedural fighter poses, special moves, and a CPU that adapts to repeated attacks, defensive habits, and special-move patterns. Fighter art is original procedural vector artwork, not official anime sprites or character likeness assets.

## Controls

- A / D or ← / →: move
- W / ↑ / Space: jump
- J: light attack
- K: heavy attack
- L: special attack
- I: guard
- On touch screens, use the on-screen controls.
