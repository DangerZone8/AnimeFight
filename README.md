# AnimeFight

A browser-based 2D anime crossover fighting game. Built with vanilla JavaScript and the Canvas 2D API so it runs as a static site and deploys cleanly to Vercel.

## Development

- `npm test` — run the AI and game-logic tests
- `npm run build` — validate the static production files
- `npm run dev` — start a local static development server

## Current scope

The first playable milestone includes a character roster, local player-versus-CPU matches, round timer, health and energy meters, keyboard and touch controls, special moves, and an adaptive CPU that tracks repeated player behaviour. Character visuals are original stylized interpretations rather than copied anime artwork.

## Controls

- A / D or ← / →: move
- W / ↑ / Space: jump
- J: light attack
- K: heavy attack
- L: special attack
- I: guard
- On touch screens, use the on-screen controls.
